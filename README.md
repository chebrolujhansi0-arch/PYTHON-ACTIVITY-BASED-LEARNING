Introduction
This repository contains 10 Python case study programs developed as part of the Activity-Based Learning (ABL) assignment. These programs solve simple real-world problems using basic Python programming concepts.

List of Case Studies
1. University Scholarship Allocation
This program checks whether a student is eligible for a scholarship based on aggregate marks, attendance percentage, and annual family income.

Concepts Used: Variables, data types, operators, and conditional statements.

2. Progressive Electricity Billing
This program calculates an electricity bill based on the number of units consumed using different rates for different unit ranges.

Concepts Used: Variables, arithmetic operators, and if-elif-else statements.

3. Employee Payroll and Deduction Analysis
This program calculates an employee's HRA, DA, deductions, and net salary based on the basic salary.

Concepts Used: Variables, arithmetic operators, and calculations.

4. Retail Billing with Multiple Discount Rules
This program calculates the discount and final bill amount based on the customer's purchase amount.

Concepts Used: Variables, operators, and conditional statements.

5. Campus Event Financial Planning
This program calculates the total income, expenses, and remaining balance for a campus event.

Concepts Used: Variables, arithmetic operators, and conditional statements.

6. Examination Result and Grace-Mark Validation
This program checks a student's examination result based on the marks entered and displays the result.

Concepts Used: Variables, comparison operators, and conditional statements.

7. Attendance Recovery Computation
This program calculates a student's attendance percentage and checks whether the attendance requirement is satisfied.

Concepts Used: Variables, arithmetic operators, and conditional statements.

8. ATM Transaction Sequence Simulation
This program simulates basic ATM operations such as checking the balance, depositing money, and withdrawing money.

Concepts Used: Variables, loops, conditional statements, and arithmetic operators.

9. Warehouse Inventory Reconciliation
This program displays the available stock of items and updates the stock after a sale.

Concepts Used: Lists, loops, conditional statements, and list operations.

10. Advanced Numeric Pattern Generator
This program generates a number pattern based on the number of rows entered by the user.

Concepts Used: Nested loops, variables, and print statements.
